# Локальное однопроцессное приложение с FastAPI и SQLite

Приложение работает только на компьютере оператора: один процесс обслуживает локальную веб-панель, расписание и последовательную очередь отправки. FastAPI предоставляет HTTP-интерфейс, SQLite хранит конфигурацию и историю, а серверные HTML-страницы с небольшим JavaScript не требуют Node.js. Такой вариант выбран вместо отдельного фронтенда, удалённого сервера и нескольких фоновых служб, чтобы MVP оставался устанавливаемым и диагностируемым одним процессом.
