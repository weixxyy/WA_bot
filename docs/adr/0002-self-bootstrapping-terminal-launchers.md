# Самонастраивающиеся терминальные скрипты вместо собранных приложений

Windows, macOS и Linux получают терминальные скрипты запуска, которые через `uv` устанавливают управляемый Python, зависимости и совместимый Firefox Playwright при первом запуске, а затем открывают локальную панель. Собранные исполняемые файлы и браузер внутри дистрибутива отклонены для MVP: они потребовали бы отдельной сборки и подписи для каждой платформы; компромисс — обязательный интернет при первом запуске и возможный запрос `sudo` для системных библиотек Firefox на Linux.
