# WA_bot — бот WhatsApp Web

Бот на Playwright (Firefox), который заходит по invite-ссылкам в группы WhatsApp
и отправляет в них сообщение. Ссылки лежат в `urls_list.py`.

## Требования

- Python 3.10+ (проверено на 3.14)
- Playwright 1.63 и скачанный браузер Firefox
- Linux / macOS / Windows

## Быстрый старт

Linux / macOS:

```bash
./setup.sh
./run.sh                # по расписанию: 09:00 и 18:00, пока не остановишь Ctrl+C
./run.sh --once         # один прогон и выход
```

Windows:

```bat
setup.bat
run.bat                 # по расписанию: 09:00 и 18:00, пока не остановишь Ctrl+C
run.bat --once          # один прогон и выход
```

То же самое вручную: `.venv/bin/python main.py` (Windows:
`.venv\Scripts\python.exe main.py`). Подробности — в разделе
«Расписание запусков» ниже.

Добавить новый аккаунт или удалить существующий профиль (интерактивно) —
`./login.sh` на Linux / macOS и `login.bat` на Windows.

Скрипт установки создаёт `.venv`, ставит зависимости, скачивает Firefox для
Playwright и создаёт пустой каталог `profiles/`.

## Расписание запусков (`run.sh` / `run.bat`)

Бот не висит в памяти постоянно, а просыпается в заданные времена суток —
`scheduler.DEFAULT_RUN_AT` (по умолчанию 09:00 и 18:00, **местное время
машины**). Времена можно переопределить из командной строки:

```bash
./run.sh --at 10:30 22:15        # Windows: run.bat --at 10:30 22:15
```

Что важно знать:

- ближайшее время считается **заново после каждого прогона**. Если прогон занял
  больше времени, чем пауза до следующего слота, слот пропускается и не
  «догоняется»;
- ошибка внутри прогона (Playwright, сеть, проблемный профиль) не останавливает
  планировщик: она попадает в лог (`logs/wa_bot.log`), а следующий запуск всё
  равно планируется;
- остановить бота можно `Ctrl+C` — это штатное завершение, без стек-трейса;
- время указывается в формате `ЧЧ:ММ`, дубликаты схлопываются, а опечатка в
  `--at` приводит к понятной ошибке сразу, ещё до первого прогона;
- `--once` выполняет один прогон и выходит — удобно для отладки и для запуска
  извне (например, из системного `cron` или `systemd` timer).

То же самое вручную (без обёрток `run.sh` / `run.bat`):

```bash
.venv/bin/python main.py                       # по расписанию
.venv/bin/python main.py --once                # один прогон
.venv/bin/python main.py --at 09:00 18:00      # свои времена
.venv/bin/python main.py --help
```

## Установка вручную

```bash
python -m venv .venv                  # 1. окружение
source .venv/bin/activate             #    Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt   # 2. зависимости
python -m playwright install firefox  # 3. браузер (без него бот не запустится)
# Linux, если не хватает системных библиотек:
# python -m playwright install-deps firefox
mkdir -p profiles                     # 4. каталог профилей (создаётся и самим ботом)
python main.py                        # 5. запуск
```

В PyCharm: выберите интерпретатор `.venv` — зависимости из `requirements.txt`
подтянутся при синхронизации окружения, шаг с `playwright install firefox`
нужно выполнить из терминала один раз.

## Каталог `profiles/`

Внутри `profiles/` лежит по одному каталогу Firefox-профиля на каждый аккаунт
WhatsApp (например `profiles/whatsapp_profile1` или `profiles/7` — имя профиля
задаётся при его добавлении). В профиле хранится сессия
WhatsApp Web (`cookies.sqlite`, `key4.db`, `storage`), то есть фактический доступ
к аккаунту, поэтому:

- содержимое `profiles/` **никогда не коммитится** (см. `.gitignore`);
- в git попадает только заглушка `profiles/.gitkeep`, чтобы папка появлялась
  сразу после клонирования проекта;
- каталог создаётся автоматически (`login_check.ensure_profiles_dir()`) при
  первом запуске — даже если `profiles/` отсутствует или пуст.

Чтобы добавить аккаунт, положите в `profiles/` каталог с уже выполненным входом
в WhatsApp Web (Firefox) — либо добавьте его интерактивно, см. раздел
«Управление аккаунтами» ниже. Там же профиль можно удалить (вручную это то же
самое — просто удалить его каталог).

## Управление аккаунтами (`login.sh` / `login.bat`)

`login.py` умеет и добавлять аккаунты, и удалять профили. С аргументами он
браузер не открывает: можно просто посмотреть список профилей или удалить
нужные.

Linux / macOS:

```bash
./login.sh                          # интерактивное меню
./login.sh --list                   # показать профили из profiles/
./login.sh --delete 7               # удалить профиль profiles/7 (с подтверждением)
./login.sh --delete 7 8 --yes       # удалить без подтверждения
```

Windows:

```bat
login.bat
login.bat --list
login.bat --delete 7
login.bat --delete 7 8 --yes
```

То же самое вручную:

```bash
.venv/bin/python login.py           # Windows: .venv\Scripts\python.exe login.py
```

### Добавление аккаунтов

Скрипт спрашивает, сколько аккаунтов добавить, и как назвать каждый профиль
(введённый номер становится именем каталога в `profiles/`). После этого по
очереди открывается окно Firefox на web.whatsapp.com — нужно отсканировать
QR-код телефоном и нажать Enter в консоли. Браузер открывается видимым
(не headless), иначе QR-код не отсканировать.

```
Управление аккаунтами WhatsApp
  1 — добавить аккаунты
  2 — удалить профиль
  0 — выйти
Действие [1]:
Сколько аккаунтов хотите добавить? 2
Название (номер) профиля №1: 7
Название (номер) профиля №2: 8
```

Enter в меню — это пункт 1, то есть добавление: без аргументов скрипт ведёт
себя так же, как раньше. В результате появятся каталоги `profiles/7` и
`profiles/8`. Существующие профили скрипт не трогает: если каталог с таким
номером уже есть, он попросит ввести другой номер.

### Удаление профиля

Удаление необратимо: вместе с каталогом профиля пропадают сессия WhatsApp
(`cookies.sqlite`, `key4.db`, `storage`) и файл `bot_stats.json` — аккаунт
придётся добавлять заново. Поэтому скрипт сначала показывает полные пути и
спрашивает подтверждение (`[y/N]`, по умолчанию — нет).

```
Действие [1]: 2
Доступные профили:
  1) whatsapp_profile1
Номера или названия профилей (Enter — отмена): 1

Будут удалены:
  /home/user/WA_bot/profiles/whatsapp_profile1
Вместе с профилем удалится сессия WhatsApp и файл bot_stats.json — аккаунт придётся добавлять заново.
Продолжить? [y/N]: y
Профиль /home/user/WA_bot/profiles/whatsapp_profile1 удалён.
```

Что стоит знать:

- профиль указывается номером из списка или именем каталога: `1`, `7`, `7, 8`;
- если бот сейчас работает, удаление отклоняется — сначала остановите его
  (Ctrl+C). Обойти проверку можно только осознанно, флагом `--force`;
- удаляются только каталоги внутри `profiles/`: пути вида `../что-то` и
  служебные файлы (`.gitkeep`) отклоняются;
- каталог профиля можно удалить и вручную — результат тот же.

## Статистика профиля: `bot_stats.json`

В каждом каталоге профиля бот ведёт файл `bot_stats.json` (например
`profiles/whatsapp_profile1/bot_stats.json`). Он создаётся автоматически
перед обходом ссылок и содержит:

- `kicked_count` — сколько групп, из которых аккаунт был выгнан, встретилось
  за текущий прогон (в начале работы с профилем счётчик обнуляется);
- `last_date_change` — время последней записи в файл (ISO-формат,
  например `2026-09-25T16:12:33`).

Файл лежит внутри `profiles/`, поэтому в git он не попадает.

## Как это работает

1. `main.py` — точка входа: настраивает логи, разбирает аргументы (`--once`,
   `--at`, `--force`) и либо делает один прогон (`run_once()`), либо отдаёт его
   планировщику. Пока бот работает, он держит блокировку `logs/wa_bot.lock`
   (`bot_lock.py`), поэтому второй экземпляр без `--force` не стартует: два
   прогона по одним профилям ломают Firefox-профиль. Прогон: создаёт
   `profiles/`, запускает Playwright, проверяет профили и обходит группы;
   ошибка на одном профиле не прерывает остальные.
2. `scheduler.py` — расписание: считает ближайшее время из
   `DEFAULT_RUN_AT`, спит до него и вызывает прогон; упавший прогон не
   останавливает цикл (см. «Расписание запусков»).
3. `login.py` (`login.sh` / `login.bat`) — управление аккаунтами: интерактивное
   меню из двух действий (добавить аккаунты и удалить профиль) плюс разовые
   команды `--list` / `--delete` (см. «Управление аккаунтами»).
4. `login_check.py` — проверяет каждый профиль из `profiles/`
   (`check_profile()` открывает web.whatsapp.com) и делит их на `logged` /
   `unlogged`; если страница не открылась (сеть, DNS, прокси), профиль
   пропускается с ошибкой в логе, а остальные проверяются дальше.
5. `script.py` — для каждого залогиненного профиля создаёт/обнуляет
   `bot_stats.json`, проходит по ссылкам из `urls_list.py`, вступает в группу
   и отправляет сообщение; если аккаунт из группы выгнали, увеличивает
   `kicked_count`.
6. `logger.py` — логи в консоль и в `logs/wa_bot.log` с ротацией.
7. `bot_lock.py` — блокировка `logs/wa_bot.lock`: не даёт запустить второй
   экземпляр бота (`main.py`) и удалить профиль во время прогона (`login.py`).

## Настройка

- Ссылки-приглашения: `urls_list.py` → `INVITE_URLS`.
- Времена автозапуска: `scheduler.DEFAULT_RUN_AT` либо аргумент `--at`
  (см. «Расписание запусков»).
- Уровень и файл логов: `logger.setup_logging(level=..., log_file=...)`.
- Каталог профилей: константа `PROFILES_DIR` в `login_check.py`
  (по умолчанию `<каталог проекта>/profiles`).
- Файл блокировки запуска: `LOCK_FILE` в `bot_lock.py`
  (по умолчанию `<каталог проекта>/logs/wa_bot.lock`).

## Частые проблемы

- `Executable doesn't exist at .../firefox-...` — не выполнен
  `python -m playwright install firefox`.
- `Firefox не запускается, не хватает библиотек` (Linux) —
  `python -m playwright install-deps firefox` (нужен sudo).
- В логе `В .../profiles нет ни одного авторизованного профиля` — в `profiles/`
  ещё нет ни одного каталога с выполненным входом в WhatsApp Web.
- В логе `Не удалось открыть WhatsApp Web для профиля ...` и
  `Профиль ... пропущен: не удалось проверить` — страница не загрузилась
  (нет сети, блокировка, прокси). Такой профиль не попадает ни в `logged`,
  ни в `unlogged`, остальные проверяются дальше.
- В логе `Бот уже запущен ...` — второй экземпляр бота не стартует, пока
  работает первый (блокировка `logs/wa_bot.lock`). Остановите работающий бот
  (Ctrl+C) либо запустите с `--force`, если второй прогон действительно нужен.
- `Не удалось удалить ... каталог занят` — в этот момент работает бот или
  Firefox держит профиль. Остановите бота (Ctrl+C), закройте Firefox и
  повторите: `./login.sh --delete <имя>`.

## Безопасность

Каталог `profiles/` (а также `logs/`) исключён из git. Не публикуйте содержимое
профилей: оно даёт полный доступ к аккаунту WhatsApp. Удаление профиля
необратимо — сессия WhatsApp и `bot_stats.json` пропадают вместе с каталогом.
