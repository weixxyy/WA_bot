# WA Bot

Локальное приложение с веб-панелью для отправки общего текста и изображений в
группы WhatsApp от имени нескольких аккаунтов. Панель работает только на этом
компьютере (`127.0.0.1`) и не требует отдельного удалённого сервера.

## Запуск для пользователя

При первом запуске нужен интернет. Скрипт сам скачивает `uv`, управляемый
Python 3.12, зависимости приложения и совместимый Firefox Playwright. Обычный
Firefox из системы не используется: Playwright требует собственную сборку.

### Windows 10/11 x64

Дважды щёлкните `start.cmd`. Откроется терминал, а затем панель в браузере.
PowerShell запускается через служебную обёртку, поэтому менять Execution Policy
вручную не нужно.

### macOS на Apple Silicon

Дважды щёлкните `start.command` или выполните:

```bash
./start.command
```

Если архив потерял права на запуск, один раз выполните:

```bash
chmod +x setup.sh start.sh start.command repair.sh run.sh login.sh
```

### Ubuntu 22.04/24.04 x64

```bash
./start.sh
```

При первой установке системных библиотек Firefox Ubuntu может запросить пароль
`sudo`.

## Как остановить

Закрытие вкладки браузера **не останавливает** приложение. Чтобы остановить
панель, расписание и бота, нажмите `Ctrl+C` в терминале или закройте вкладку
терминала. Приложение перестанет брать новые группы, попытается завершить
текущую операцию и закроет браузер.

Повторный запуск, пока приложение уже работает, не создаёт второй экземпляр, а
открывает существующую панель.

## Первоначальная настройка

1. Откройте раздел **Аккаунты**.
2. Задайте понятное имя аккаунта и нажмите **Открыть QR-вход**.
3. В появившемся Firefox отсканируйте QR-код телефоном. Панель сама определит
   успешный вход; нажимать Enter в терминале не нужно.
4. В разделе **Группы** вставьте ссылки `chat.whatsapp.com`. Можно вставить
   произвольный текст или загрузить UTF-8 файл `.txt`: ссылки извлекаются и
   дубликаты удаляются автоматически.
5. Настройте текст, emoji и изображения в разделе **Сообщение**.
6. Настройте дни, время, паузу и лимит попыток в разделе **Расписание**.
7. Включите расписание либо нажмите **Запустить сейчас** на главной странице.

## Поведение рассылки

- каждый включённый аккаунт пишет в каждую включённую группу;
- поддерживается до 10 аккаунтов;
- список рассчитан как минимум на 10 000 групп и показывается постранично;
- перед запуском считается число попыток `аккаунты × группы`;
- лимит по умолчанию — 500 попыток, его можно изменить в панели;
- аккаунты и группы обрабатываются последовательно;
- пауза между группами случайная, по умолчанию 4–8 секунд;
- текст можно отправлять отдельно или подписью к изображениям;
- поддерживаются JPG, PNG, WEBP и GIF до 25 МБ на файл;
- большое количество изображений автоматически делится на пачки;
- ошибка одной группы или аккаунта не останавливает остальные;
- безопасная ошибка до отправки повторяется один раз;
- неоднозначный результат после начала отправки не повторяется, чтобы не
  создавать дубль.

## Расписание

Расписание поддерживает несколько времён и любые дни недели. Часовой пояс
берётся из операционной системы и перечитывается во время работы. Изменение
настроек сразу пересчитывает следующий запуск.

Пропущенные из-за сна или выключения компьютера запуски не догоняются. Если
предыдущий прогон ещё работает, новый слот пропускается и записывается в
историю.

## Управление данными

Настройки, база SQLite, изображения, логи и Firefox-профили хранятся отдельно
от кода:

- Windows: `%LOCALAPPDATA%\WA_bot`;
- macOS: `~/Library/Application Support/WA_bot`;
- Linux: `~/.local/share/WA_bot`.

Путь можно переопределить переменной `WA_BOT_DATA_DIR`. Замена папки с кодом не
удаляет данные пользователя.

Firefox-профиль содержит действующую WhatsApp-сессию. Не публикуйте и не
передавайте каталог данных целиком. Удаление аккаунта из панели необратимо;
для временного исключения используйте переключатель **Включён**.

При первом запуске новая версия копирует профили старой версии из локальной
папки `profiles/`, не удаляя оригиналы. Старые ссылки импортируются только если
обнаружены признаки существовавшей установки. Чистая установка начинает с
пустого списка групп.

## История и диагностика

Панель хранит 30 дней истории прогонов и результаты по каждой паре
«аккаунт × группа». Раздел **Журнал** показывает последние 500 строк файла
`logs/wa_bot.log` из каталога данных. Полные invite-ссылки в журнал не пишутся.

Если окружение повредилось:

- Windows: запустите `repair.cmd`;
- macOS/Linux: запустите `./repair.sh`.

Repair пересоздаёт `.venv`, повторно ставит зависимости и проверяет Firefox,
но не трогает пользовательские настройки и профили.

## Совместимые старые команды

`run.sh`, `run.bat`, `login.sh` и `login.bat` оставлены как обёртки и теперь
открывают локальную панель. Для одиночного прогона без панели после настройки:

```bash
./.venv/bin/python main.py --once
```

## Разработка и проверки

```bash
./setup.sh
.tools/uv/uv --system-certs pip install --python .venv/bin/python -r requirements-dev.txt
.venv/bin/python -m pytest -q
.venv/bin/ruff check .
```

Архитектурные решения описаны в `docs/adr/`, предметный словарь — в
`CONTEXT.md`.

## Ограничение автоматизации

WhatsApp Web не предоставляет этому проекту стабильный публичный API. Его DOM
и элементы управления могут измениться. Все ожидания ограничены тайм-аутами,
а неизвестные состояния записываются как ошибки вместо бесконечного зависания,
но после существенного обновления WhatsApp селекторы могут потребовать правки.
