Текст сообщения

Содержимое файла send_to.txt. Многострочный текст уходит одним сообщением.

Ссылки-приглашения

Файл urls.txt: по одной ссылке в строке, строки с # — комментарии.

Импорт ссылок из текста

Вставьте любой текст — панель выловит ссылки вида chat.whatsapp.com/... и добавит новые.

Отсортированные ссылки

Заполняется скриптом вступления: only_admins_groups.txt, closed_groups.txt, open_groups.txt. Редактировать не нужно — это результат прогонов.

Только админы — only_admins_groups.txt

Запрос на вступление — closed_groups.txt

Остальные — open_groups.txt

Расписание

Хранится в settings.json и применяется сразу, без перезапуска панели.

Расписание вступления в группы

Отдельное расписание для скрипта join_groups.py: он только вступает в группы и раскладывает их по файлам, не отправляя сообщений.
